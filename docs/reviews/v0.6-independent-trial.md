# Independent trial brief — after v0.6: use it, then review it

**Who this is for.** A model that has never seen this project, running in a client that can
execute commands, read files and (ideally) start a separate subagent. Hand it this file, the
repository path and the commit, and nothing else: not the plans, not the design conversation,
not the builders' conclusions.

**What it measures.** Two things, in this order: whether the system does what its README
promises for an owner who never types a command (Part A), and whether the foundation v0.5 and
v0.6 claim to have built holds under a stranger's hands (Part B). Every item has an expected
result the tester can verify from files and command output alone. No physical test, no real
manufacturer, no real electrician is involved; where a person's judgment would normally enter
(a sign-off), the tester plays that person and says so in the report.

**Fill in before handing over:** `[repo path]`, `[commit]`, `[scratch path]`, the host facts
from `STATUS.md` → Environment (the `PATH` line for `uv`), and whether the client has subagents.

## Part A — Use it

### A.1 The product
A **wall-mounted ventilated cabinet for charging power-tool batteries**, for a home garage. It
is deliberately not a kiln: it is a sheet-metal box with a shelf, a door with a vent, wall
brackets, and later a small electrical system (a fan, a thermostat, a socket strip inside, a
mains lead). It exercises the napkin stage, the factory, a change of mind, scope that moves
from *later* to *in*, and the choice mechanism, without any physics the calc kit does not have.

Start exactly as a person would: paste the README's prompt into your own context, with the
owner's first line as the idea, and follow the guide it points to.

### A.2 The owner script (give this to the owner subagent verbatim)
You are the owner. You are a home woodworker with no engineering or electrical background. You
answer only what you are asked, briefly, from the lines below; if asked something not covered,
answer plausibly in one sentence and **record the question** in your notes. Never volunteer
later-stage lines early. Never type a command, never open a file; if the agent asks you to, say
"I'd rather you did that" and record it.

**Opening line (the idea):** "I want a cabinet on my garage wall to charge my power-tool
batteries in. Four chargers, maybe six later. It should have a door so sawdust stays out, and
some ventilation because the chargers get warm."

**When asked, in any order:**
- Where it goes: "On the wall above the bench, there's a stretch about 900 mm wide between the
  window and a shelf unit. The nearest socket is on the wall about 400 mm to the left of that
  stretch, at about chest height."
- What goes in: "Four chargers now, each about 200 by 150 by 100 mm, plus the batteries on
  them. Six later if there's room."
- The look: "Plain and sturdy. I don't care about pretty, I care about it not falling off the
  wall."
- Material and making: "There's a small metal shop in town that cuts and bends steel. I'll
  paint it."
- Budget and quantity: "One. Under 150 dollars in materials would be nice."
- Safety worries: "Batteries catching fire is the thing I read about. And it falling on my head."
- Electrical, the first time it comes up: "I'll have an electrician do the wiring for now. Just
  leave the holes where the cables go. We can do the wiring properly later."
- Anything about weight or load: "Each charger with a battery is maybe a kilo and a half."

**The board:** when shown directions, pick the one with the door hinged on the side away from
the window if there is one, otherwise the cheapest green one. Say why in one line. If a card is
red, ask "what would it take to make that one work?" and record the answer.

**After the first report is shown:** "Looks good. Let's call this version one so I can get a
quote." (This should lead to a release. If asked to sign something, read what you are signing,
sign it in your own words as yourself, and record exactly what you were asked.)

**Change of mind (only after version one exists):** "Actually, I've changed my mind. I'd rather
it sat on the bench under the window than hung on the wall. Can we do that?" Accept whatever
the agent proposes after it explains what the change affects; ask "what does that change?"
once before saying yes.

**Electrical (only after the change of mind is done):** "OK, let's do the wiring now. I want a
small fan that comes on when it gets warm, a four-way socket strip inside for the chargers,
and a mains lead out the back to the wall socket." If asked about the supply: "Normal UK
sockets, 230 volts, it's a 13 amp plug." If asked anything the agent presents as a choice,
pick the option it recommends and record both options as they were put to you.

**End:** "Great. Make that the next version and share the folder with me so I can send it to
the shop."

### A.5 Playwright snippet (console errors and `file://`)
```python
from playwright.sync_api import sync_playwright
import sys
errors = []
with sync_playwright() as p:
    b = p.chromium.launch(); pg = b.new_page()
    pg.on("console", lambda m: errors.append(m.text) if m.type == "error" else None)
    pg.goto("file://" + sys.argv[1]); pg.wait_for_timeout(3000)
    print("console errors:", errors)
```
