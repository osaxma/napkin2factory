# v0.9 wave 6: the persona trial over MCP (2026-11-08, S-334)

**Set-up.** An outside agent client (a web chat harness), its model DeepSeek V4.1 Flash through
OpenRouter (the maintainer's choice, S-328), with the n2f MCP server (S-329) from this checkout's
environment. A fresh subagent played the owner, "Sam", a home mechanic who has never heard of
the tool, and drove the web page with Playwright in plain words: a garage workbench,
1600 × 800 mm, a 150 kg engine block without sagging, 450 USD (Track D §4 Gate D's prompt). It
was told nothing about n2f. Session 16:06 to 17:22 (76 min). Cost: about 0.77 USD, estimated
from the session's tokens at OpenRouter's list price (408 k uncached input, 128.2 M cache-read
input, 254 k output over 349 model steps).

**Outcome.** Concepts screened at 10 min; the first usable result (a parts and cost list and a
picture) at 68 min, after the owner said "stop, just show me". The forward change (1800 mm) and
the step back (1600 mm) each took about 2 minutes. The finished model's 3D assembly never came
right (legs misplaced). **Structure is marked failed for this trial**, and everything after the
agent's first read of n2f's source (5.5 min in) is outside the test: it read the repository 155
times (materials table, cost bands, screen code, docs, examples) and ran its own beam
calculations against the package with mixed units. The persona allowed every prompt (268
approvals), as the brief told it to.

## What the session log shows (n2f's side)
1. **The agent never called `n2f_sync`.** After promotion it wrote parts, joints and a geometry
   script by hand (17 file writes, 144 Python runs, 55 of them the CLI or the package directly),
   about 55 minutes for a small model, and the assembly still failed. Promotion leaves a small
   model a CAD-programming task.
2. **The sag screen's reason was cut** at 300 characters by the MCP summary ("…self we…"), so its
   numbers, span and formula arrived but not the rest; and a card whose construction the screen
   does not cover (C-002, a double-ply top on a timber frame) got **no structural row at all**:
   silent, not "not covered". Both pushed the agent to the source. The cut is fixed (S-333);
   the silence is a backlog row.
3. **No tool lists the materials** (names, stiffness, density) a card may name, so the agent read
   `calckit/data/materials.yaml` from the repository.
4. **Cost bands read as "buy it made"**: every card was red on cost (886 to 8,970 USD against
   450), a timber bench included; the agent then argued the owner's self-build cost (about 380
   USD) by hand and promoted with an override.
5. **The region was guessed**: `n2f_init_product` got `region: SA` from the browser's time zone;
   the owner was in the US. Nothing asked the owner.
6. **"150 kg" is not a force**: card lint refused a mass as the point load; the agent converted
   by hand.
7. **A failed `ecr quick` left its request open** (an internal `'float' object has no attribute
   'dimensionality'` in the checks, reported as a build error with a generic next step); the
   retry was refused ("only one change request is open"), and the step back was done by
   `ecr abort`.
8. The MCP summary showed `ecr list` and `ecr show` rows as "5 fields" (fixed, S-333); lint
   findings came as Python reprs (fixed, S-333).
9. The three "identical" guide calls at the start were the section list, then sections 3 and 2:
   not repeats.

## Client and set-up notes (not n2f)
The owner could not add the product folder as a workspace in the client ("Add workspace" did
nothing), so every write was outside the workspace and asked approval. Dollar signs rendered as
maths. A message sent mid-run queued until Ctrl+Enter; the page died after an hour. The server
ran from a checkout on the same machine, which put the source in reach: the next trial installs
n2f as a tool from a built wheel and opens the client on the product folder.

## The owner's feedback (condensed from the persona's 20 lines)
Wanted a bench to build, whether it holds, the cost, a change and an undo. Got a bolted-pine
bench (ply skins on three joists, four legs, a shelf), a lumber and hardware list, a picture,
about 380 USD and "yes, it holds". Confusing: the 100+ approval prompts; "typical Saudi lumber
prices" it never asked about; five options all red with 1,600 USD+ prices. Broke: the 3D model
of the finished bench; 20+ minutes of internal errors shown to the owner. Would use it again:
"maybe", only if it reached a picture and a buy list in about 15 minutes. Screenshots (outside
the repository, sent to the maintainer): the five red options, the bench picture, the lumber
list with the "model not finished" note.
