## What the next version should know first

- **One client kind.** Every trial so far ran in a terminal agent harness. §2.1 asks for an IDE agent
  and a desktop chat app over MCP too; the MCP server exists (S-255) but no trial has used it.
- **Gate B starts from a product with a model**, not from a spec, so its time-to-report (5 min) is not
  v0.7's from-scratch row (14 to 43 min). Both agents read `ecr close`'s list of 13 to 14 sign-offs as
  the surprise of the run; under `standard` ceremony a product never signed meets all of them at its
  first close. B-0288 still adds two seeded copies.
- **Iteration speed is the open number.** The warm one-parameter rebuild is 19.4 s on tier 1 against a
  1 s target (v0.7: 14.4 s, measured at another load); the no-change build sits at its 2 s target only
  when the host is quiet. Each sign-off costs about 20 s (B-0269).
- **Core files:** 19 distinct `core/` files since v0.7.0 (17 at S-276, then `core/checks/stage.py` in
  S-282 and the manifest's default pin in S-284).
- **Oracle:** the design-change rows (table ECR-2, test-stand CR-2) are still pending; a gate B product is
  judged at the checkpoint before the agent's own design change (S-279).
