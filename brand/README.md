# napkin2factory logo

A napkin with a ballpoint sketch of a hexagon and a handwritten "n2f". Above it floats the
finished part: an orange hex plate with "n2f" cut through it. Dashed projection lines join the
two: the idea on the napkin, and its path to a real part.

Everything here is generated by [`build.py`](build.py). To change the logo, change a parameter
and rebuild. Don't hand-edit the SVG or PNG outputs.

```bash
python3 brand/build.py            # SVGs + PNGs + favicon.ico (needs rsvg-convert; ICO needs ImageMagick)
python3 brand/build.py --no-png   # SVGs only (standard library, no other tools)
```

Open [`preview.html`](preview.html) in a browser to see every asset and the animation.

## Files

| File | Use |
|---|---|
| `svg/n2f-icon.svg` | Master icon (dark tile). Use at 48 px and up. |
| `svg/n2f-icon-32.svg` | Simplified for about 24–47 px: no dots, no writing, bold outline, two projection lines. |
| `svg/n2f-icon-16.svg` | Simplified for 16–23 px: napkin, hexagon outline and part only. |
| `svg/n2f-mark.svg` | The master without its tile, for dark backgrounds only. |
| `svg/n2f-icon-animated.svg` | The master with a CSS intro animation (see below). |
| `svg/n2f-lockup-on-dark.svg`, `svg/n2f-lockup-on-light.svg` | Icon + wordmark. |
| `png/n2f-icon-{1024…64}.png`, `png/n2f-icon-{48,32,16}.png`, `png/favicon.ico` | Raster exports (48 and 32 come from the 32 variant, 16 from the 16 variant). |

## Construction

- **Canvas:** 100 × 100, 2:1 isometric. A point (a, b, z) on the napkin plane maps to
  `x = 50 + a − b`, `y = cy + (a + b)/2 − z`. `cy` is chosen so the group (napkin tip to plate
  top) is vertically centred.
- **Master parameters:**
  - Overall scale: 0.86. The napkin is ±18.9 units.
  - Hexagon: radius 13.8.
  - Napkin-to-part gap: 36 units.
  - Plate: 3.2 thick.
  - Projection lines: on vertices 2, 1 and 5 (left, front-left, right). The front vertex is
    skipped so no line crosses the handwriting.
- **Hand-drawn look:** seeded randomness (`sketch_seed`, `word_seed`), so every build is
  identical. Change a seed to get a different, equally valid hand.
- **Variants:** the `Variant` dataclass holds every size variant. The three in use are
  `MASTER`, `SMALL_32` and `SMALL_16`.

## Animating

Each SVG is built from named layers, so motion work reuses these files instead of redrawing.

| Layer id | Contents |
|---|---|
| `tile` | Background tile. |
| `napkin` | `napkin-sheet`, `napkin-creases`, `napkin-dots`, `napkin-fold`. |
| `sketch` | `sketch-outline` (6 pen strokes) and `sketch-word` (4 pen strokes), in drawing order. Each path has `pathLength="1"`, so a stroke-dashoffset 1→0 draws it on. |
| `projection` | `projection-1…3`, one `<line>` each, from napkin vertex to plate. |
| `part` | The plate faces, `part-top` and `part-cut` (`cut-n`, `cut-2`, `cut-f`). It carries `data-gap`: translate it down by that many units to set it on the napkin. |

`n2f-icon-animated.svg` is a working example in plain CSS, about 3 s, played once:
1. The pen draws the hexagon, then writes "n2f".
2. The projection lines grow upward.
3. The part lifts off into place.

It respects `prefers-reduced-motion`. The layered SVG also imports cleanly into Figma, After
Effects (and from there Lottie) or Rive.

## Use

- **Clear space:** at least 10% of the icon's width on every side.
- **Size:** use the 32 and 16 variants at their sizes. Don't scale the master below 48 px.
- **Backgrounds:** the tile is part of the mark. Put the bare mark only on dark backgrounds.
- **Don't:** recolour the parts, rotate the projection, or replace the handwriting with a font.
- **Wordmark:** the lockups set "napkin2factory" as live text (Inter, falling back to Helvetica
  or Arial). Once a typeface is chosen and licensed, outline the text so it renders the same
  everywhere.
